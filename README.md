# 🐾 Yuva Bul

A Flutter-based mobile application designed to help stray and shelter animals find homes. Users can browse adoptable pets, save their favorites, create adoption listings, and manage their profiles through a modern and intuitive interface.

---

## 📱 Overview

Yuva Bul is a mobile pet adoption application developed using Flutter and Firebase. The application aims to simplify the pet adoption process by connecting people who want to adopt with animals in need of a home.

The entire UI/UX was designed in Figma before development, focusing on a clean, responsive, and user-friendly experience.

---

## ✨ Features

- User Authentication
- Browse pets available for adoption
- View detailed information about each animal
- Search and filtering animal informations
- Add or remove pets from Favorites
- User Profile Management
- View profile picture
- Create new pet adoption listings
- Firebase backend integration
- Responsive mobile interface
